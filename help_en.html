SampleDir Help

Add Sample Folders

  • Click the + button in the FOLDERS panel on the left to add a folder to your library.
  • You can also drag a folder or individual audio files into the window.
  • The Features → Add Folder menu works as well.

Browse & Audition

  • Click folders in the tree on the left to expand sub-directories; the list on the right shows all samples in the current directory.
  • Double-click any row to audition; double-click again or press Space to pause / resume.
  • ↑ ↓ move between samples (auto-audition), Enter replays from the start.

Search & Filter

  • Type keywords in the top search box to search by file name (space-separated words).
  • Click a tag in the TAGS panel to filter samples under that tag.
  • ⌘F focuses the search box, Esc clears all filters.

Favorites

  • Click the ⭐ at the row head to favorite / unfavorite.
  • ALL FAVORITES shows everything you've favorited; "默认收藏" shows only directly favorited samples.
  • Create named collections: click + next to ALL FAVORITES and name it.
  • In the detail panel, quickly add the current sample to any collection.

Notes & Tags

  • With a sample selected, write notes in the right detail panel (auto-saved, 2-second debounce).
  • Notes are searchable — any keyword matches.
  • The "添加标签" button tags a sample; tags are also searchable and filterable.

Sorting & Column Settings

  • Click a column header to sort (click again to toggle ascending / descending).
  • Right-click a header to show / hide columns, or drag to adjust width and order.

Waveform & Scrubbing

  • The lower part of the detail panel shows the sample's waveform (1200-point RMS).
  • Click anywhere on the waveform to start playback from that position.
  • The waveform engine can be switched in Settings (Java Sound / ffmpeg).

Keyboard Shortcuts

  • Space — Play / Pause
  • ↑ ↓ — Move between samples
  • Enter — Replay selected sample from start
  • ⌘F — Focus search box
  • ⌘, — Open Settings
  • Esc — Clear all filters

Settings

  • Click the ⚙ icon at top-right or press ⌘, to open Settings.
  • Language: switch between 中文 / English instantly.
  • Appearance: System / Light / Dark.
  • Font size: scales interface text proportionally.
  • Waveform engine: Java Sound or ffmpeg (ffmpeg is more accurate for MPEG-encoded .wav).
  • Show file extensions: whether to display suffixes like .wav at the end of file names.
