## ★ 语言 URL 从 ?lang= 参数改为真实路径（2026-10-07，commit 0198e24）
- 根因定性：全站 canonical/sitemap/hreflang 全是 `?lang=` 参数 URL，Google 对参数 URL 收录优先级极低
  → 4 个语言页全卡「已发现-尚未编入索引」；根 URL canonical 又指 ?lang=zh，全站没有可落地规范 URL。
- 改造（URL 即语言）：
  - `_redirects`（新增，仓库根）：`/en|/ko|/ja`（含尾斜杠）→ `/index.html 200` 代理（CF Pages rewrite，URL 不变）。
  - `index.html` head 两个脚本：①路径前缀判语言 + 旧 `?lang=xx` 一次性 `location.replace('/xx/')`
    （带 search+hash；`?autodl=1` 的 App 更新跳转豁免不重定向）；②根路径按「localStorage 偏好 → 浏览器区域
    （bot 一律 zh）」落到 /en/ /ko/ /ja/，保证根 URL 恒为中文渲染 + canonical 自指。
  - canonical/hreflang 全路径化：`langUrl(lang)`（zh→BASE，其余→BASE+lang+'/'）。
  - 资源与站内链接全部绝对路径（`/assets/...`、`/help.html`…），否则 /en/ 下相对路径 404。
    没用 `<base>`（会破坏 `#锚点` 链接）。
  - `main.js`：`pathLang()`/`langPath()`；getLang() 路径优先（根=zh，不再读 localStorage/locale——
    head 重定向已兜）；语言切换器改为 `location.assign(langPath(lang)+hash)`；页脚 help/terms/privacy
    链接改绝对路径且按语言切换（terms_en/privacy_en 之前一直没接上，顺手修了）。
  - `sitemap.xml`：4 URL 路径化。
- **本地验证手法**：CF `_redirects` 本地无效，写了 /tmp/langsvr.py（单段路径 /en|/ko|/ja → index.html 的
  http.server 模拟）+ agent-browser 验证；无头 Chrome 的 `--dump-dom` 对 localhost 输出为空（线上 https 正常），
  localhost 必须用 agent-browser。`agent-browser storage local set/clear` 可造 localStorage 偏好。
- 线上验证（push 后）：/en/ /ko/ /ja/ 均 200 且 canonical 自指、title 对应语言、绝对资源路径生效；
  dump-dom 解析线上三 URL 全对。GSC 需重交 sitemap + 对 4 个新路径各「请求编入索引」。
- 顺带核实：官网 version.json 与 55 双 appcast 一致均为 1.0.1（与记忆中"已还原 1.0.4"不符——
  55 上的文件后来被 1.0.1 覆盖过或从未更到 1.0.4；发版时留意）。
