## 官网留言板（公开留言 + 人工审核 + 邮件通知）

用户需求：官网加留言功能（官网部署在 Cloudflare Pages）。方向确认：**公开留言板 + 邮件通知 + 人工审核**。

**技术路线**：纯 CF 全家桶 —— Cloudflare **D1**（SQLite，免费 5GB）做存储，Pages Function `functions/api/messages.js` 读写，Resend 发邮件（唯一第三方，免费档 100 封/天）。

**新增/改动文件**（`webs/SampleDir/`，未提交 git，用户自己提交）：
- `wrangler.toml`：加 `[[d1_databases]]` binding=DB（database_id 占位 `REPLACE_WITH_DATABASE_ID`）+ `[vars] RESEND_FROM`。
- `migrations/0001_init.sql`：messages 表（id/name/email/content/lang/status/ip_hash/created_at）+ status+created_at 索引。
- `functions/api/messages.js`：GET 返回 status=approved 留言（限 50）；POST 提交（honeypot `website` 字段 + 同 IP 60s 限频 + 邮箱校验 + IP 存 SHA-256 hash 不存明文）写 pending 并发 Resend 邮件（带 approve/delete HMAC 链接）；GET `/admin?action=approve|delete&id&token` 审核（HMAC-SHA256(ADMIN_SECRET,id) 验签，无需登录后台）。
- `index.html`：`#contact` 后新增 `#guestbook` section（表单：昵称/邮箱/内容 + honeypot 隐藏字段 + 状态提示 + 留言列表容器）。
- `assets/js/main.js`：I18N 四语言字典加 `gb.*` 12 条；applyLang 新增 `data-i18n-ph`（placeholder）支持；新增「6. 留言板」逻辑（拉取/渲染 XSS 转义/提交/状态提示）。
- `assets/css/styles.css`：`.gb-form/.gb-item/.gb-status` 等留言板样式（沿用深色主题变量 + green 主色）。

**部署步骤（用户需手动，关键）**：
1. `npx wrangler d1 create sampledir_messages` → 拿到 database_id 填进 wrangler.toml。
2. `npx wrangler d1 execute sampledir_messages --remote --file=migrations/0001_init.sql` 建表。
3. 设 secrets（不进 git）：`RESEND_API_KEY`（resend.com 拿）、`ADMIN_SECRET`（任意随机串，用于审核链接验签）、`ADMIN_EMAIL`（可选，默认 hhztiger@gmail.com）。
4. `git add` + `git commit` + `git push` → CF Pages 自动 rebuild。

**要点**：审核链接从邮件点击即可通过/删除留言，无需后台界面；留言 status 默认 pending 不显示；审核通过后 GET /api/messages 才返回。邮件里 approve/delete 链接用 `new URL(request.url).origin` 动态拼接，不硬编码域名。
