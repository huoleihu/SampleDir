# SampleDir

**A local-first sample library manager for music producers.**

Turn the audio samples scattered across your disks into a searchable, auditionable, annotated library — no cloud, no account, no lock-in.

## Highlights

- 🗂️ **Folders are the library** — add any folder (or several) as a root, and every audio sample inside is gathered into one place.
- 🏷️ **Smart tag recognition** — BPM, key, instrument, genre and type are inferred from file and folder names, rendered as color-coded tags.
- 🎧 **Instant audition** — double-click to play, arrow keys to audition in sequence, Enter to replay, Space to pause.
- 📈 **Visual waveforms** — every sample shows a waveform preview; click anywhere on it to jump-play from that position.
- ⭐ **Annotate everything** — notes, tags, star ratings, favorites and named collections, all auto-saved.
- 🧳 **Your work travels with your folders** — copy a sample folder to another machine, rescan, and your notes, ratings and favorites come right back.
- 🖱️ **Drag & drop into your DAW** — drag a sample straight into Logic Pro, GarageBand, or any file manager.
- 🔒 **Local-first & private** — all data stays on your disk. No account, no cloud, no telemetry.
- 💻 **Cross-platform** — native macOS (Apple Silicon & Intel) and Windows builds, each following its platform's UI conventions.

## Features

**Library management**
- Add or remove multiple sample root directories (e.g. a mobile drive plus an internal sample disk)
- Smart incremental rescan — only new or changed files are re-processed, so repeat scans are fast

**Metadata & recognition**
- Per-sample duration, sample rate, channels, format, size and path
- Auto tags from file + folder names: BPM, key, instrument (Kick, Snare, Clap, 808, Bass, Piano, Hat, Perc…), genre (Trap, HipHop, House, LoFi…), type (Loop, OneShot, FX, Foley, Vocal…)

**Audition & waveform**
- Play / pause / stop, volume control; a persistent bottom transport bar stays visible while you scroll
- Waveform preview for every sample, cached for smooth browsing

**Search, filter & sort**
- Live full-text search across file names, notes and tags (results appear as you type)
- Multi-dimensional filtering: instrument / genre / type / BPM / key / format / favorites
- Sort by name, BPM, key, duration, format, rating or modified time — ascending or descending
- One-click "favorites only" view

**Annotation & organization**
- Free-text notes per sample, 5-star ratings, favorites
- Custom tags plus named collections (e.g. "Drum kits", "Drop material") that group samples across roots

**Integration & UX**
- Drag samples out to DAWs / file managers
- Three-pane workspace: roots & collections · sample table · detail panel with a large waveform
- Native menus, title bars and dialogs on each platform
- Customizable columns (show / hide / order), light & dark themes

## FAQ

**Q: Some samples get no tags.** — Recognition is based on file and folder naming. The more consistent your naming, the more accurate the tags; arbitrarily named files may not be recognized — that's expected, not a bug.

**Q: Is my data uploaded anywhere?** — No. SampleDir is local-first by design — everything stays on your machine, with no account and no cloud.
