SampleDir 使用帮助

添加采样文件夹

  • 左侧「FOLDERS」区点击 + 按钮，选择一个文件夹加入库。
  • 支持拖拽文件夹或单个音频文件到窗口。
  • 菜单「功能 → 添加文件夹」同样可用。

浏览与试听

  • 点击左侧文件夹树展开子目录，右侧列表显示当前目录下的所有采样。
  • 双击任意行即可试听；再次双击或按 Space 暂停 / 恢复。
  • ↑ ↓ 方向键上下切换采样（自动试听），Enter 从头重播。

搜索与筛选

  • 顶部搜索框输入关键词即可按文件名搜索（空格分隔多个词）。
  • 点击左侧标签（TAGS）区域可筛选该标签下的采样。
  • ⌘F 快速聚焦搜索框，Esc 清除全部筛选。

收藏

  • 点击行首 ⭐ 即可收藏 / 取消收藏。
  • 左侧「ALL FAVORITES」显示全部收藏，「默认收藏」仅显示直接收藏的采样。
  • 可创建命名收藏夹：点击 ALL FAVORITES 旁的 + 并命名。
  • 详情面板中可快速将当前采样加入任意收藏夹。

备注与标签

  • 选中采样后在右侧详情面板可写备注（自动保存，2 秒防抖）。
  • 备注支持搜索，输入任意关键词即可匹配。
  • 下方「添加标签」按钮可为采样打标，标签同样可搜索和筛选。

列表排序与列设置

  • 点击表头即可按该列排序（再次点击切换升序 / 降序）。
  • 表头右键可自定义列的显示 / 隐藏、拖拽调整宽度和顺序。

波形与跳播

  • 详情面板下半部分显示当前采样的波形（1200 点 RMS）。
  • 点击波形图任意位置可从该处开始播放。
  • 波形引擎可在设置中切换（Java Sound / ffmpeg）。

键盘快捷键

  • Space — 播放 / 暂停
  • ↑ ↓ — 上下选择采样
  • Enter — 从头重播选中的采样
  • ⌘F — 聚焦搜索框
  • ⌘, — 打开设置
  • Esc — 清除所有筛选

设置

  • 点击右上角 ⚙ 图标或 ⌘, 打开设置面板。
  • 语言：中文 / English 即时切换。
  • 外观：跟随系统 / 浅色 / 深色。
  • 字体大小：等比缩放界面文字。
  • 波形引擎：Java Sound 或 ffmpeg（ffmpeg 对 MPEG 编码的 .wav 更准）。
  • 显示文件扩展名：列表文件名末尾是否显示 .wav 等后缀。
